# Giulia approved knowledge bases

Drop lab-approved source material into these logical sets when available:

- `shared/` — context both specialist roles may use.
- `cultural/` — cultural/social/communication material.
- `business/` — professional/workplace/business material.

For the first intra-lab prototype, these can remain ordinary Markdown or text files under version control. Retrieval can be added later if the combined context becomes too large or costly to send directly.

Giulia has no web-search or browsing tools. Knowledge must come from these approved local materials, system prompts, and the active conversation.
